# حشمت صیادپرست (حشمت صیاد) — وب‌سایت رسمی

**«بولدوزر دانشگاه»** — پروفایل رسمی حشمت صیاد پرست، فوتبالیست سرسخت و خوش‌اخلاق
زادهٔ بدرهٔ ایلام.

🌐 **وب‌سایت زنده:** [https://heshmatsayad.github.io/](https://heshmatsayad.github.io/)

این ریپو منبع وب‌سایت پروفایل است که با GitHub Pages منتشر می‌شود.

## محتوا

- درباره و مسیر فوتبال (از زمین‌های خاکی بدره تا تیم‌های بیمارستانی تهران)
- سبک بازی و لقب «بولدوزر دانشگاه»
- پیوندها: [پروفایل گیت‌هاب](https://github.com/HeshmatSayad)،
  [دانشگاه علوم پزشکی تهران](https://www.tums.ac.ir/)،
  [فدراسیون فوتبال ایران](https://www.ffiri.ir/)

## فناوری

HTML + CSS + JavaScript خالص، فارسی راست‌چین، فونت self-hosted وزیر،
تصاویر WebP با fallback، دادهٔ ساختاریافته JSON-LD (ProfilePage/Person)،
و سئوی کامل (canonical، robots، sitemap، Open Graph، Twitter Card).
